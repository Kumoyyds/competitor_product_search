# Matching Module

**Status**: Skeleton (not yet implemented)

## Responsibility

Compares SKU attributes against scraped product data for precise match scoring. Goes beyond URL-level matching to verify product identity at the attribute level (brand, model, size, color, quantity).

## Inputs / Outputs

- **Input**: SKU data (from models) + scraped product data (from scraping)
- **Output**: Match results with confidence scores
